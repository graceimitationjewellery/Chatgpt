GRACE IMITATION JEWELLERY - WEBSITE STARTER

Files:
- index.html
- style.css
- app.js

How to publish:
1. Upload all three files into the root of your GitHub repository.
2. In GitHub open Settings > Pages.
3. Under Build and deployment choose "Deploy from a branch".
4. Select branch "main" and folder "/ (root)", then Save.
5. Wait for GitHub Pages to publish the site.

IMPORTANT LIMITATION:
This starter has a browser-only admin PIN and saves product/logo changes in the same browser's local storage. It is NOT secure authentication and changes do NOT automatically appear on customers' devices. Before using it as a live business admin system, connect a cloud database and secure authentication/storage. Do not treat the PIN in app.js as secure.
